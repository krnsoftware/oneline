# Changelog

## 0.1.1

- Remove dependency on Ruby's full `cgi` library.
- Add `oneline_http.rb` with the minimal HTTP/form helpers needed by oneline.
- Support both `application/x-www-form-urlencoded` and `multipart/form-data` without the `cgi` gem.
- Keep the memo data format, edit event format, authentication files, and Shortcut API unchanged.

## 0.1.0

- Initial packaged release.
