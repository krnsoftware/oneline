# Data format

## メモ本体

`data/YYYY-MM.txt`

1物理行 = 1メモです。フィールド区切りはTABです。

```text
RFC3339日時<TAB>16桁hex ID<TAB>本文
```

例:

```text
2026-11-01T01:42:15+09:00\ta7c31d9e842fb610\tメモ本文
```

本文中の改行・TABは保存前に空白へ正規化されます。

ファイル名やディレクトリだけに日時情報を依存せず、各レコード自身が完全な日時を持ちます。

## 修正イベント

`edits/edits.txt`

```text
RFC3339日時<TAB>対象ID<TAB>action<TAB>本文
```

action:

- `E`: Edit。本文に修正版を保存
- `D`: Delete。本文は空。tombstoneを追加
- `R`: Restore。本文は空。削除状態を解除

元のメモ本体は編集・削除時にも書き換えません。

表示時には元データへイベントを順番に重ね、現在状態を生成します。

## 復元性

`data/` の月別ファイル名や配置が壊れても、各レコード内の日時とIDを使って再構成できます。
